## Шаг 1: Запустите локальный сервер

### Вариант 1: Встроенный PHP сервер (рекомендуется)
1. Откройте командную строку (Win + R → `cmd` → Enter)
2. Перейдите в папку проекта:
   ```bash
   cd "C:\Users\kiril\OneDrive\Рабочий стол\диплом\KIMOSHI - сайт"
   ```
3. Запустите сервер:
   ```bash
   php -S localhost:8000
   ```
4. Сервер запущен! Оставьте окно командной строки открытым.

### Вариант 2: OpenServer

2. Перейдите на ваш домен (например, `http://kimoshi.local`)

## Шаг 2: Проверьте соединение с Telegram

1. Откройте в браузере:
   ```
   http://localhost:8000/test_telegram.php
   ```
   (или замените на ваш домен, если используете OpenServer)

2. На странице отобразятся результаты тестов:
   - ✅ **PHP версия** — должна быть 7.0+
   - ✅ **cURL расширение** — должно быть установлено
   - ✅ **Соединение с Telegram API** — должен отправиться тестовое сообщение
   - ✅ **Информация о боте** — проверка токена

3. **Проверьте Telegram**:
   - Откройте чат с ботом (ID: `8031234667`)
   - Должно прийти тестовое сообщение: "🧪 Тестовое сообщение"

### Если тесты не прошли:
- **cURL не установлен**: Откройте `php.ini`, найдите `;extension=curl` и уберите `;` (раскомментируйте)
- **Ошибка отправки в Telegram**: 
  - Проверьте токен бота
  - Убедитесь, что бот добавлен в чат с указанным ID
  - Проверьте интернет-соединение

## Шаг 3: Проверьте отправку заказа

1. Откройте страницу оформления заказа:
   ```
   http://localhost:8000/parts/Оформить заказ/Checkout.html
   ```

2. **Убедитесь, что в корзине есть товары**:
   - Если корзина пуста, перейдите в каталог и добавьте товары

3. **Заполните форму**:
   - ФИО: например, "Иванов Иван Иванович"
   - Телефон: например, "+7 (999) 123-45-67"
   - Адрес доставки: например, "г. Москва, ул. Примерная, д. 1"
   - Способ оплаты: выберите любой
   - Комментарий (необязательно): можно оставить пустым

4. **Нажмите "Подтвердить заказ"**

5. **Что должно произойти**:
   - Кнопка изменится на "Отправка заказа..." с иконкой загрузки
   - Появится всплывающее уведомление:
     - ✅ **Успех**: "Заказ успешно отправлен!" (зеленое)
     - ❌ **Ошибка**: "Ошибка отправки заказа..." (красное)
   - Через 2 секунды произойдет перенаправление на главную страницу

6. **Проверьте Telegram**:
   - Откройте чат с ботом (ID: `8031234667`)
   - Должно прийти сообщение с данными заказа:
     - ФИО
     - Телефон
     - Адрес доставки
     - Способ оплаты
     - Список товаров с количеством и ценами
     - Общая сумма
     - Комментарий (если был указан)
     - Дата и время

     - Посмотрите статус ответа (должен быть `200`)
     - Откройте запрос и проверьте ответ сервера

## Возможные проблемы и решения

### ❌ Проблема: "Ошибка соединения с сервером"
**Решение:**
- Убедитесь, что локальный сервер запущен
- Проверьте путь к `send_order.php` (должен быть в корне проекта)
- Проверьте, что вы открываете сайт через `http://localhost:8000`, а не через `file://`

### ❌ Проблема: "Ошибка отправки в Telegram"
**Решение:**
1. Проверьте токен бота в `send_order.php` (строка 37)
2. Проверьте ID чата в `send_order.php` (строка 38)
3. Убедитесь, что бот добавлен в чат с указанным ID
4. Запустите `test_telegram.php` для диагностики

### ❌ Проблема: "cURL extension not found"
**Решение:**
1. Найдите файл `php.ini` (обычно в папке с PHP)
2. Откройте его в текстовом редакторе
3. Найдите строку: `;extension=curl`
4. Уберите `;` в начале: `extension=curl`
5. Сохраните файл и перезапустите сервер

### ❌ Проблема: "404 Not Found" для send_order.php
**Решение:**
- Убедитесь, что файл `send_order.php` находится в корне проекта
- Проверьте путь в JavaScript: `fetch('../../send_order.php', ...)`
- Откройте `http://localhost:8000/send_order.php` напрямую (должен вернуть JSON с ошибкой валидации)

### ❌ Проблема: PHP код отображается как текст
**Решение:**
- PHP не обрабатывается — убедитесь, что сервер запущен через `php -S localhost:8000`
- Не открывайте файлы через `file://` — используйте `http://localhost:8000`
